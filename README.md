# 薄荷溪居 · 第一版

> 阶段 0 基线：现有网页行为保持不变。下一版已确定改为个人单用户、GitHub Pages + Cloudflare Workers + D1；将删除邀请、亲友分享和全部用户图片功能，并彻底移除 R2。详见 [架构说明](docs/ARCHITECTURE.md)、[数据迁移说明](docs/DATA_MIGRATION.md)和[恢复说明](docs/RECOVERY.md)。

已完成本地功能版。尚未开通云端数据库、图片存储或公网托管，当前不是可发给亲友的正式网站。

## 现在可用

- 植物屋顶小屋、溪流、薄荷与奶黄花束水彩界面。
- 邮箱与密码登录；首次创建个人空间；管理员生成邀请链接，最多 5 人。
- 睡眠、学习、餐饮记录，运动、清洁和每日 SOP 打卡。
- 21 项运动与清洁预设；可编辑、停用、自定义频率和目标。
- 按月统计与日期筛选；跨月历史保存。
- 本月重点独立保存，自定义模块显示。
- Excel 导入预览、去重、分批保存与导出。
- 每条记录最多 6 张 PNG、JPG 或 WebP 图片，单张不超过 5 MB。
- 按记录选择亲友进行只读分享，撤销后图片访问同时失效。

原始 Excel 文件未修改。用户预览数据库与验收数据库分离，未向用户空间填入示例记录。

## 本机使用

在本地预览服务运行时打开 http://localhost:5173/ 。此地址仅指向当前设备，不能直接发给亲友使用。

首次点击“创建空间”，填写自己的昵称、邮箱和至少 12 位密码。仅保存密码派生值，不保存明文密码。邮箱目前用于账号识别和邀请绑定，不会自动发邮件。请妥善保存密码；第一版没有邮件找回密码。

本地数据位于项目的 `.wrangler/state`。不要删除这个目录。Excel 导出不包含图片文件；图片可在记录详情中打开并另存。

## 源码安装与运行

需要 Node.js 22.13 或更新版本。源码 ZIP 解压到独立目录后执行：

```powershell
npm ci
npm run build
node scripts/init-local.mjs
npm run dev
```

使用服务器打印的 Local URL。停止进程后页面无法访问，但本地记录保留。再次运行 `npm run dev` 可恢复。

如 Windows 的 npm 命令包装出现错误，可用 Node 执行已安装 npm 的 `npm-cli.js`，或直接运行 `node scripts/run-framework.mjs dev` / `build`。不要修改系统 Node 配置。

## 统计口径

- 睡眠按起床日记录，支持跨午夜，入睡和起床时间相同不作为 24 小时睡眠。
- 平均睡眠只计算有完整时间的记录；不熬夜根据个人设置的参考时间计算。
- 学习投入为实际分钟合计；计划时间和实际时间分别保留。
- 食堂用餐率分母仅包含明确填写“是/否”的日期；缺失不当作“否”。
- 单餐平均时长只计算有数字分钟的午餐、晚餐；原模板“较短/较长”等描述不擅自换算，导入时提示并留空。
- 运动次数按项目完成记录统计，一天完成多个项目分别计次。
- 清洁完成率按启用清洁项目的月目标计算，无固定月目标时根据周期计算；未记录显示缺失状态。
- 每两周项目以 2026-01-05 所在周为起点；每月 29–31 日项目在短月份落到月底。

## 已验证与边界

隔离的本地接口验收通过 14 组检查，覆盖登录、人数上限、跨站写入拦截、数据隔离、并发冲突、图片、分享撤销、导入去重、跨月历史和退出登录。

Excel 与日期计算通过 9 组检查，包含四类记录导出后重新导入、布尔值和时间保留、闰月、月底及双周周日处理、读取用户原始空白模板。

桌面和窄屏界面曾在预览中检查；最后一轮浏览器控制连接不可用，手机交互仍需实际设备验收。WebMCP 的登录后工具调用未做完整浏览器验证，不影响普通网页使用。

## 已确认的迁移方向

目标是个人单用户长期使用：静态前端部署到 GitHub Pages，API 使用 Cloudflare Workers Free，数据使用 Cloudflare D1 Free，GitHub Actions 每天自动备份。网络目标为免费、跨设备公网访问、尽力覆盖中国大陆网络，不承诺大陆稳定性。

后续版本不保存用户图片。阶段 1 将删除图片上传、查看、删除、分享撤销及全部多人功能；静态水彩界面素材继续保留。具体范围和阶段见 [架构说明](docs/ARCHITECTURE.md)。

不购买域名，不绑定付款方式，不启用付费服务或按量计费。阶段 0 只建立本地恢复点，没有创建或连接任何云端资源。
